# Immersive Visit VR — SVR 2026

This repository contains the Unity project files for the **Rehabilitation Clinic** architectural scene developed for the work presented at SVR 2026.

Two versions of the scene are included:

- **VR version** — developed for the Meta Quest 3S, using waypoint navigation and hand tracking.
- **PC version** — adapted for desktop use, allowing navigation with keyboard and mouse.

## Scene

The project represents a rehabilitation clinic developed in a BIM environment and converted into an interactive environment using Unity.

## Technologies

- Unity
- Meta Quest 3S
- XR Interaction Toolkit
- OpenXR

## Versions

### VR

The VR version provides an immersive visualization of the rehabilitation clinic. Users can navigate through predefined waypoints using hand-tracking gestures.

### PC

The PC version provides the same architectural environment in a desktop application, using keyboard and mouse for navigation.
